01/04
Viettel Solutions · 2023–25

TesselAI · retail shelf scoring

I found the opportunity, wrote the business case, then built and released it: computer vision that scores market photographs automatically and retires manual field-audit review.

  • YOLOA single-pass object detector: one look at the frame returns every box it found, fast enough for live video.
  • SegmentationPixel-level outlines instead of boxes — what separates one product facing from the one behind it.
  • TritonNVIDIA's inference server. It batches requests across a GPU so one model can serve many callers at once.
  • ONNXA portable model format: train in one framework, run anywhere, usually faster than the original runtime.
120 RPS at TP95 · in commercial use · ~3× on the same GPUTP95 means 95% of requests finished faster than this. It describes the slow tail, which is what a user actually feels, not the average.

[ HOW I WORK ][ HOW I WORK ]

Anyone can make a model agree with them.

The job is building something that can be audited.

A

Automation proposes, a human approves

Nothing the system infers is treated as fact until a person confirms it.

B

No silent failure

Dead-letter queues and diagnosable errors. A failed evaluation is always visible and recoverable.

C

Honest test gates

Accuracy checks that skip rather than pass when real validation data is missing. False assurance is worse than none.

D

Access control by design

Separation enforced in the token, least-privilege responses, permissions on the actions that matter.

E

Reversible releases

Continuous delivery with automatic rollback, and runbooks so nothing depends on one person being reachable.

F

Handover as a deliverable

Architecture and operating documentation written alongside the code, not after it.
